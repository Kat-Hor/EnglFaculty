What is GitHub Pages? 🤔

GitHub is a website where people store files in folders called repositories. Programmers use it for code — but we teachers can use it for something much nicer: GitHub Pages.

GitHub Pages turns the HTML files in a repository into a real website with its own link. Students open the link in any browser (iPad, phone, laptop, smartboard) and the material simply works — quizzes, flashcards, tabs, buttons and all.

Think of it as a pinboard on the internet: you pin up your pages once, and everybody with the link can look at them. 📌

How-to in 5 steps 🚀

Create a free account

Go to github.com and sign up. Your username becomes part of your web address later — so choose something short and professional (e.g. mrs-miller).

Make a new repository

Click the green New button (or + → New repository). Give it a name like English8, set it to Public and click Create repository.

Upload your files

Click Add file → Upload files, drag your files into the box and click Commit changes (= "save"). Important: your start page must be called index.html! Pictures can go into a folder called images.

Switch on GitHub Pages

In your repository go to Settings → Pages. Under "Build and deployment" choose Deploy from a branch, select the branch main and the folder / (root), then click Save.

Wait a minute & share the link 🎉

After 1–2 minutes your website is online. The link always looks like this:

https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/
⚠️ Public means public! Never upload student names, grades, photos of students or anything else that falls under data protection. Teaching materials only.

GitHub words decoded 🔍

Repository ("repo")A project folder — e.g. one per course or unit.
CommitSaving your changes. Every commit is stored, so you can always go back.
Branch "main"The main version of your folder. For us, there's only this one.
index.htmlThe start page. It opens automatically when someone visits your link.
HTML & CSSHTML is the content of a page, CSS its look (colours, fonts). You don't have to write either yourself (see FAQ 😉).
Public / PrivateFor free GitHub Pages, the repository has to be public.

FAQ 🙋

Do I need to know how to code?

No! I create my pages with the help of an AI assistant: I describe what I want (topic, exercises, colours, level) and get finished HTML files. Then I check the content, change what I don't like and upload them. You can also simply copy and adapt an existing page.

Does it really cost nothing?

Yes. A free GitHub account plus a public repository is all you need for GitHub Pages.

How do I change a page later?

Open the file in your repository, click the pencil icon ✏️ to edit it directly — or upload a new version with the same file name. Commit, wait a minute, refresh. Done!

My link shows "404"! Help! 😱

Don't panic. Check: Is the start page really called index.html (all lower case)? Did you switch on Pages in the settings? Did you wait 1–2 minutes? Also: file names are case-sensitive — Quiz.html and quiz.html are two different files.

How do students get to the page?

Post the link on LernSax, write it on the board or create a QR code (many free QR generators exist). Students don't need an account.

Can I put pictures on my pages?

Yes — upload them into an images folder in the repository and link them in the HTML. Only use pictures you are allowed to use (your own, or with a free licence) and never photos of students.
